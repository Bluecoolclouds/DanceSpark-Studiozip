# Приёмка подписанного Android-релиза

**Статус: не выполнено.** Заполнять по установленному release APK, не по Expo Go или браузеру. Пароли и токены здесь не записывать.

Перед началом зафиксировать версию/versionCode, SHA-256 APK, отпечаток сертификата, модель устройства/Android, дату и проверенный постоянный API. Для смены аккаунтов нужны два обычных тестовых аккаунта. Для удаления — отдельный одноразовый.

| Сценарий | Ожидаемый результат | Статус |
|---|---|---|
| Чистая установка | Нет debug-режима, запускается без Metro и VPN к рабочей среде | Не проверено |
| Документы без входа | Политика и контакты открываются без сессии | Не проверено |
| Регистрация / вход | Email/пароль, русская ошибка неверного пароля, нет ложного обещания писем | Не проверено |
| Перезапуск приложения | Действующая сессия восстанавливается безопасно | Не проверено |
| Выход → другой аккаунт | Нет чужих черновиков, медиа, кредитов и данных администратора | Не проверено |
| Потеря сети / истёкшая сессия | Понятная ошибка; нет повторной платной отправки | Не проверено |
| Выбор фото/видео | Выбранный материал соответствует предпросмотру и отправке | Не проверено |
| Камера | Запрашивается по действию пользователя, без записи звука | Не проверено |
| Отказ разрешений | Нет падения, можно отменить/выбрать другой способ; при постоянном отказе доступен переход в настройки | Не проверено |
| Разрешения | Нет геолокации, микрофона, наложений и биометрии; manifest соответствует декларации | Не проверено |
| Каталог | Реальные постеры и примеры воспроизводятся, нет пустых/подставленных исходников | Не проверено |
| Генерация — только с разрешённым бюджетом | Одна отправка, корректное списание и результат, отсутствие самовольного повторного запроса | Не проверено |
| Закрытие во время задания | После открытия — read-only восстановление статуса, без нового платного запроса | Не проверено |
| Сохранение и отправка | Видео декодируется, появляется в галерее, системный share работает | Не проверено |
| Удаление аккаунта | Подтверждение УДАЛИТЬ; собственные данные и сессии удаляются, каталог/чужие данные остаются | Не проверено |
| Удаление с активным/неопределённым заданием | Явный безопасный отказ, нет потери задания/бюджета | Не проверено |
| Недостаток кредитов | Понятный отказ, нет оплаты, которая фактически не подключена | Не проверено |
| Обновление приложения | При наличии предыдущей версии: тот же сертификат/package, повышенный versionCode, данные не смешиваются | Не проверено |

Дефект записывать как: шаг → ожидаемо → фактически → версия. Не включать фотографии пользователей, полный email, signed URL, токены, ключи или секретные ответы поставщика.

Нельзя отметить всю таблицу пройденной после проверки только регистрации. Подпись и наличие HTTP 200 не доказывают воспроизведение видео или работу native-разрешений.
