## Разрешения Android

| Разрешение | Назначение / решение |
|---|---|
| INTERNET | API, загрузка медиа, генерация и получение результата |
| VIBRATE | Тактильный отклик интерфейса |
| CAMERA | Сделать исходное фото; только после действия пользователя |
| READ_MEDIA_VIDEO / READ_MEDIA_VISUAL_USER_SELECTED | Работа с выбранными видео и разрешёнными пользователем материалами |
| READ_EXTERNAL_STORAGE / WRITE_EXTERNAL_STORAGE | Совместимость медиатеки на старых Android; Expo ограничивает manifest SDK 32 |
| RECORD_AUDIO | Заблокировано: запись звука не нужна |
| ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION / ACCESS_BACKGROUND_LOCATION | Заблокировано: геолокация не используется |
| SYSTEM_ALERT_WINDOW | Заблокировано: нет наложений поверх других приложений |
| USE_BIOMETRIC / USE_FINGERPRINT | Заблокировано: биометрический вход не используется |

Проверена конфигурация Expo introspect: запреты представлены как `tools:node="remove"`. Это **не** финальный Android merged manifest. Перед отправкой проверить именно свежий APK/AAB: зависимости могут добавлять разрешения. Нельзя считать старый подписанный файл исправленным изменением `app.json`.

## Оплата и бесплатные кредиты

Для Android-версии этого магазина владелец выбрал подписки **RuStore Pay SDK**. ЮKassa остаётся прежним планом только для веба. Обе интеграции пока не реализованы, покупки выключены. См. `docs/payments/rustore-readiness.md` от корня проекта. Зарегистрированные аккаунты имеют дневные бесплатные кредиты по серверным правилам; это не означает неограниченной или гарантированной генерации. Гости генерацию не получают.

Не заявлять, что для генерации всегда обязательна платная подписка: это устаревшее описание. Но и не считать дневной лимит достаточным для всех моделей — проверять стоимость и бюджет на реальном аккаунте модератора. Не запускать платные запросы без отдельного разрешения на расходы.

Для платного запуска нужен отдельный этап: настройка продуктов RuStore, официальный SDK, серверная валидация и привязка к аккаунту, договоры/цены, согласие на автосписания, отмена, уведомления, идемпотентность, сверка, возвраты и прекращение будущих списаний при удалении аккаунта.
